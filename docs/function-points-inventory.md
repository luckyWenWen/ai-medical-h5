# 智能预问诊 H5 功能点清单

生成日期：2026-09-07  
清点范围：当前仓库代码、路由、页面、状态管理、接口封装，以及 `需求.md` 中的规划内容。  
统计口径：以可独立验收的页面入口、业务动作、状态控制、接口能力为功能点；纯样式、图片素材、重复工具函数不单独计数。

## 一、总体结论

当前仓库主要是“患者端 H5”，不是完整的后台管理端或医生端系统。

| 范围 | 功能点数量 | 说明 |

| 当前代码已具备功能点 | 201 | 患者端 H5 已有页面入口、业务流程、接口封装或前端降级能力 |

## 三、当前代码已具备功能点明细

### 1. 账号登录、鉴权与协议（12）

1. 账号密码登录。

4. 当前仓库没有后台管理端页面、医生端页面和后端服务代码；这些功能只在需求文档中体现。
5. 部分 README/需求文档在终端输出中存在编码显示问题，但源码内页面与接口中文可正常读取。
